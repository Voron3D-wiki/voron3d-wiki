# notes/

Internal working notes for this repo — not part of the published wiki, and
not read by the Astro build. This is for whoever is working on the repo next,
human or AI: todo lists, known bugs, planned fixes, anything that's about the
repo rather than for a wiki reader.

If a note describes something a reader of the site needs to know (a
limitation, a caveat), it belongs in the actual content page instead. If it
describes something the *next person working on this repo* needs to know,
it belongs here.
