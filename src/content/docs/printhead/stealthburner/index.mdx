## Overview

Stealthburner (SB) is VORON Design's toolhead for full-size VORON printers such as the
V2.4 and Trident.
It is paired with the **Clockwork2** (CW2) extruder, and the two are released
together from the same repository. Stealthburner replaced the
[Afterburner](/printhead/afterburner/) and is still the default toolhead in the
official build manuals.

It is no longer the only official option: [DownDraft](/printhead/downdraft/) is a newer,
modular VORON toolhead aimed at builders who want more choice of hotend, extruder and
part-cooling fan. Both mount to the same carriage pattern, so either works on the
stock X carriage or on [Chariot](/printhead/chariot/).

## Why choose Stealthburner

- **It is the reference toolhead.** The official manuals, the default Klipper configs and
  most toolhead boards are designed around it, so it is the path with the fewest surprises
  on a first build.
- **Large community support.** Almost every common problem has already been solved and
  documented by someone else.
- **Built-in LEDs.** Neopixel logo and nozzle lighting are part of the stock design.

If you want to run a hotend Stealthburner does not support, or you want a 4010 or
dual-5015 part-cooling layout, look at [DownDraft](/printhead/downdraft/) instead.

## Latest revision (SB and CW2 update)

VORON Design released an update to Stealthburner and Clockwork2 alongside Chariot and
DownDraft. The changes:

| Change | What it means for you |
|--------|-----------------------|
| **Choice of PTFE inlet** | Use either a bowden collet or an ECAS04 fitting at the top of the extruder. |
| **Vented PCB cover** | A new cover with hexagonal ("bestagon") vents keeps toolhead boards cooler. |
| **Optional hall-effect filament sensor** | A filament sensor can now be built into the main body, without a separate add-on. |
| **Inspection window** | The old anti-squish part has been dropped. An inspection window gives better access to the BMG gears. |
| **Stronger screw seats** | Extra material ("anti-cracking beef") around the 50mm screw seats on the Stealthburner body. |
| **Two-tone multibody option** | The CAD now includes a multibody version for printing in two colours. |

There is still no built-in filament cutter.

:::tip[Upgrading an existing Stealthburner]
These are printed-part revisions, so an existing build can be upgraded by reprinting the
changed parts. Check the current BOM before you start: the inlet choice and the filament
sensor need different hardware.
:::

## Clockwork2 extruder

Clockwork2 is the extruder half of the Stealthburner assembly. It uses BMG-style dual
drive gears driven by a pancake stepper. The [Extruders](/printhead/extruders/) page
compares it with other extruder options.
